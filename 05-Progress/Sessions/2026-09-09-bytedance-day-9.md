## 新算法：LeetCode 239 滑动窗口最大值

### 题意理解

给定整数数组 `nums` 和窗口大小 `k`，窗口从左到右每次移动一格，返回每个长度为 `k` 的连续窗口中的最大值。

例子：

```text
nums = [1, 3, -1, -3, 5, 3, 6, 7]
k = 3
输出：[3, 3, 5, 5, 6, 7]
```

### 暴力法

通过：能说明每个窗口重新扫描 `k` 个元素找最大值，一共有 `n - k + 1` 个窗口，时间复杂度 `O(nk)`，辅助空间 `O(1)`（不计答案）。

### 单调队列

已建立核心直觉：

- 维护一个从队头到队尾值递减的结构；
- 队头永远是当前窗口最大值；
- 新元素进来后，队尾所有比它小的旧元素未来不可能成为最大值，可以弹出；
- 队列通常存下标，不存值，因为下标既能判断是否过期，也能通过 `nums[index]` 取值比较。

已学习 `deque<int>` 基本操作：

```cpp
dq.push_back(i);
dq.pop_front();
dq.pop_back();
dq.front();
dq.back();
dq.empty();
```

核心代码：

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;
    vector<int> ans;

    for (int i = 0; i < nums.size(); i++) {
        while (!dq.empty() && dq.front() < i - k + 1) {
            dq.pop_front();
        }

        while (!dq.empty() && nums[dq.back()] < nums[i]) {
            dq.pop_back();
        }

        dq.push_back(i);

        if (i >= k - 1) {
            ans.push_back(nums[dq.front()]);
        }
    }

    return ans;
}
```

### 239 当前掌握情况

通过点：

- 能说出暴力法与 `O(nk)`；
- 能理解“新来的大值会让队尾更小元素失效”；
- 能理解队列存下标是为了判断过期和访问数值；
- 能在提示后写出记录答案条件 `i >= k - 1`；
- 能说出辅助空间更准确为 `O(k)`（不计答案），宽松上界可写 `O(n)`。

不稳定点：

- 手推单调队列时容易把窗口范围看成单点，如 `i = 4` 时说成“下标 4”，需继续强化窗口范围 `[i-k+1, i]`；
- 容易误判边界：`dq.front() == i-k+1` 仍在窗口内，只有 `< i-k+1` 才过期；
- 初次把 `dq.back()` 当作值比较，应改为 `nums[dq.back()] < nums[i]`；
- 初次把 `nums[i]` 入队，应改为把下标 `i` 入队；
- 复杂度理由初次只说“只有一次遍历”，需补充“每个下标最多入队一次、出队一次，所以总操作数线性”。

结论：239 完成第一轮，但单调队列代码细节和边界需要 D+1 复习。
