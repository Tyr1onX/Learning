## 算法：LeetCode 283 移动零

### 核心思路

使用双指针 / 写入位置：

- `i` 从左到右扫描数组；
- `write` 表示“下一个非零元素应该放的位置”，初始为 `0`；
- 遇到非零元素时，交换 `nums[i]` 与 `nums[write]`；
- 然后 `write++`；
- 遇到零时不处理；
- 由于从左到右依次处理非零元素，非零元素的相对顺序保持不变。

独立完成实现：

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int write = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != 0) {
                swap(nums[write], nums[i]);
                write++;
            }
        }
    }
};
```

### 复杂度

- 时间复杂度：`O(n)`，数组只需从左到右扫描一遍；
- 额外空间复杂度：`O(1)`。

本次暴露的易错点：最初将空间复杂度判断为 `O(n)`，理由是“用了原数组”。修正：输入数组本身不计入算法额外空间；这里只额外使用常数个变量，因此辅助空间为 `O(1)`。
