## 新算法：LeetCode 76 最小覆盖子串

### 题意

在 `s` 中找最短连续子串，使其覆盖 `t` 中所有字符及对应出现次数。

### 第一轮建模

用户先给出朴素 `O(n^3)` 方向：枚举起点 / 终点，再扫描子串判断覆盖。

随后建立滑动窗口：

```text
不满足 → 扩 right
满足 → 缩 left，并不断更新最短答案
缩到不满足 → 继续扩 right
```

维护：

```text
need[c]   = t 对字符 c 的需求数
window[c] = 当前窗口中 c 的数量
valid     = 当前有多少种所需字符已经达到需求数量
```

当 `valid == need.size()` 时，当前窗口已覆盖全部所需字符种类，可进入收缩阶段。

### 临界更新

右侧加入：

```cpp
window[c]++;
if (window[c] == need[c]) valid++;
```

左侧移出前：

```cpp
if (window[d] == need[d]) valid--;
window[d]--;
```

用户在讲解后能够独立写出核心两个循环的正确更新顺序。

### 最短窗口

窗口使用左闭右开 `[left, right)`，长度为：

```cpp
right - left
```

在窗口仍满足条件时先比较并记录：

```cpp
start = left;
len = right - left;
```

最后可使用：

```cpp
return len == INT_MAX ? "" : s.substr(start, len);
```

### 复杂度

用户能理解整体为线性扫描；准确理由：每个字符最多被 `right` 纳入一次、被 `left` 移出一次，因此两个指针总移动次数为 `O(|s|)`；构建 `need` 另需 `O(|t|)`，平均哈希操作视为 `O(1)`。
