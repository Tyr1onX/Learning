2026-09-02：DOM / Event 基础：

- `document` 是访问当前页面 DOM 的入口；
- `document.querySelector("#id")` 返回匹配的 DOM 元素对象；
- `textContent` 可读取 / 修改元素文本；
- `addEventListener("click", handler)` 注册事件处理函数，事件发生时再执行；
- `event.target` 表示实际触发事件的元素；
- 当前易错点是 DOM API 大小写、选择器字符串引号，以及从零恢复固定语法。

2026-09-06：Promise / async-await / Event Loop 基础：

- 当前同步代码先执行；
- `Promise.then` 与 `await` 后续属于微任务；
- 当前同步代码结束后先清空微任务，再处理 `setTimeout` 等后续任务；
- `async` 函数一定返回 Promise；
- 调用 `async` 函数时会先同步执行到第一个 `await`；
- `await` 只暂停当前 async 函数后续执行，不阻塞整个 JavaScript；
- 当前易错点：综合顺序题中曾混淆 `await` 前同步执行与 `await` 后微任务，需继续间隔复习。

2026-09-09：`fetch / JSON / API` 第一轮：

- `fetch("/api/flights")` 表示浏览器 JavaScript 向后端 API 地址发送 HTTP 请求；
- API 地址通常给程序请求 / 提交数据，页面地址通常给人看页面，区别不取决于是否有查询参数；
- JSON 是轻量数据交换格式，能表示对象、数组、字符串、数字、布尔值、`null`；
- `fetch()` 先拿到 HTTP `Response` 对象；`res.json()` 才把响应体里的 JSON 文本解析成 JavaScript 对象；
- `res.ok` 判断 HTTP 状态码是否在 200～299 范围内；
- 后端根据路径和方法匹配路由，执行处理函数，可能查询数据库 / 文件 / 其他服务，再返回 JSON；
- 当前易错点：`res` 与 `data`、JSON 对象 / 数组结构识别、`res.ok` 与状态码、路由匹配术语。

这些内容仍处于第一轮 + 间隔复习阶段，不提前整体标记为 `understood`。

### 当前需要稳定的算法 / C++ 点

- `unordered_map<Key, Value>` 与 `unordered_set` 的语义区别；
- 写哈希表前先明确 key / value 的业务含义；
- `count(key)` 主要判断 key 是否存在，不等于业务上的出现次数；
- 局部基本类型变量不会自动初始化为 0；
- 复杂度分析时区分输入空间、辅助空间、输出空间；
- 49：排序后的字符串作为 key；
- 128：只有连续序列起点启动内部 `while`，平均 `O(n)`、空间 `O(n)`；
- 283：`write` 表示下一个非零元素写入位置；`O(n)` / `O(1)`；
- 11：移动较高边只会缩小宽度而短板不变，应移动较短边；
- 15：排序 + 固定 `i` + 双指针 + 去重；时间 `O(n^2)`；
- 42：依据较小的 `leftMax/rightMax` 结算对应侧；`O(n)` / `O(1)`；
- 438：固定长度滑动窗口，右进 `+1`、左出 `-1`；`O(n)` / `O(1)`；
- 560：哈希表语义为“前缀和 -> 出现次数”；每轮 `sum += x`，答案加上 `count[sum - k]`，再 `count[sum]++`；`count[0] = 1` 防止漏掉从开头开始的合法子数组；允许负数时窗口和不单调，不能简单按和大小收缩滑动窗口；平均 `O(n)` / `O(n)`；
- 239：单调队列存下标；队头用于判断过期和取当前最大值；队尾用于弹出比当前 `nums[i]` 小的下标；窗口范围是 `[i-k+1, i]`；只有 `dq.front() < i-k+1` 才过期；`i >= k-1` 后开始记录答案；时间 `O(n)` 的理由是每个下标最多入队一次、出队一次；辅助空间更准确为 `O(k)`。
