# Learning

一个长期维护的学习知识库，用于沉淀计算机基础、项目学习、面试复盘与当前学习状态。

这个仓库同时服务三个目标：

1. **自己复习**：不依赖单次聊天窗口，随时知道学过什么、忘了什么、下一步学什么。
2. **AI 辅助教学**：新会话开始时，AI 可以先读取仓库中的学习状态与知识笔记，再决定从哪里继续，而不是重新猜测基础水平。
3. **Obsidian 知识库**：仓库根目录可直接作为 Obsidian Vault 打开，笔记使用标准 Markdown、YAML Frontmatter 和 Wiki Links。

## 状态约定

每个主题尽量使用以下状态之一：

- `not-started`：尚未系统学习
- `learning`：正在学习，主干未完全稳定
- `understood`：能用自己的话解释主干
- `review-needed`：学过但容易遗忘，需要回温
- `interview-ready`：能较准确、简洁地回答常见面试追问

> 目标不是记录“看过多少”，而是记录“现在能解释到什么程度、哪里还会说错”。
